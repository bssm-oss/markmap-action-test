# 김치찌개

## 재료

### 주재료

- 묵은지
- 돼지고기 앞다리살
- 두부

### 채소

- 대파
- 양파
- 청양고추

### 양념

- 고춧가루
- 된장
- 다진 마늘
- 참기름
- 멸치 육수

## 조리 순서

### 1단계 - 재료 준비

- 돼지고기 핏물 제거
- 김치 먹기 좋은 크기로 자르기
- 두부 깍둑썰기

### 2단계 - 볶기

- 냄비에 참기름 두르기
- 돼지고기 볶기
- 김치 넣고 함께 볶기

### 3단계 - 끓이기

- 멸치 육수 붓기
- 된장, 고춧가루 추가
- 15분 이상 끓이기
- 두부, 대파 넣고 5분 더 끓이기

## 맛있게 먹는 법

- 갓 지은 흰쌀밥과 함께
- 계란프라이 추가
- 참기름 한 방울
